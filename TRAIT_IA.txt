# INTÉGRATION DE L’INTERFACE « TRAIT IA » — REPRODUIRE LA MAQUETTE EXACTEMENT

Tu dois intégrer dans l’application **TRAIT** un module entièrement dédié à **TRAIT IA**.

La priorité absolue est de **reproduire fidèlement la maquette fournie**. Ne transforme pas le design en une simple page de chat classique. Je veux une interface premium, moderne, fintech, futuriste et très propre, avec exactement l’esprit visuel de la maquette.

## 1. IDENTITÉ DE TRAIT IA

Nom affiché partout :

**TRAIT IA**

Sous-titre :

**Votre assistant intelligent**

TRAIT IA est l’assistant intelligent intégré à l’application TRAIT.

Il doit connaître le contexte de l’utilisateur connecté et adapter ses réponses à son rôle :

* Client
* Fournisseur de service
* Agent
* Administrateur

Il doit également mémoriser le nom de l’utilisateur afin de personnaliser les conversations.

Exemple :

« Bonjour, Henock Omokoko 👋 »

Puis :

« Je suis TRAIT IA, votre assistant personnel. Je connais votre rôle et je peux vous guider dans l’application selon vos besoins. »

## 2. RÈGLE FONDAMENTALE

TRAIT IA **n’effectue aucune opération financière**.

Il ne doit jamais :

* faire un dépôt ;
* effectuer un retrait ;
* envoyer de l’argent ;
* recevoir de l’argent ;
* modifier un solde ;
* valider une transaction ;
* confirmer une transaction ;
* accéder ou manipuler directement les fonds.

Son rôle est uniquement :

**EXPLIQUER → CONSEILLER → GUIDER → REDIRIGER**

Lorsqu’un utilisateur demande comment faire quelque chose, TRAIT IA explique la procédure puis peut afficher un bouton permettant d’ouvrir directement l’interface correspondante.

Exemple :

Utilisateur :
« Comment faire un transfert ? »

TRAIT IA :
« Voici les étapes pour effectuer un transfert sur TRAIT :

1. Ouvrez l’onglet Transfert.
2. Choisissez le bénéficiaire.
3. Entrez le montant.
4. Vérifiez les informations.
5. Confirmez depuis l’interface Transfert.

Voulez-vous que je vous y conduise ? »

Bouton :

**Aller à Transfert →**

Le bouton ouvre réellement la page/interface Transfert de l’application.

## 14. ARCHITECTURE TECHNIQUE

Créer TRAIT IA comme un module isolé et réutilisable.

Prévoir au minimum :

* `TraitAI`
* `TraitAIChat`
* `TraitAIWelcome`
* `TraitAIQuickActions`
* `TraitAIAbout`
* `TraitAIFloatingButton`
* `TraitAIActionButton`
* `TraitAIMessage`

Créer un système central permettant à TRAIT IA de connaître :

* `userId`
* `userName`
* `userRole`
* contexte de la page actuelle
* fonctionnalités disponibles pour ce rôle.

Par exemple :

```ts
type TraitAIRole =
  | "CLIENT"
  | "SERVICE_PROVIDER"
  | "AGENT"
  | "ADMIN";
```

Et transmettre le contexte au moteur IA.

## 15. CONNAISSANCE DU NOM

Lorsque l'utilisateur ouvre TRAIT IA, récupérer son nom depuis la session/authentification existante.

Ne jamais demander inutilement son nom s'il est déjà disponible.

Afficher son nom naturellement dans la conversation.

Exemple :

« Bonjour Henock 👋 »

Lors des conversations suivantes, conserver le contexte utilisateur selon l'architecture existante du projet.

## 16. NAVIGATION

TRAIT IA doit pouvoir déclencher une navigation interne sûre.

Exemple :

```ts
{
  label: "Ouvrir Transfert",
  route: "/transfer"
}
```

Mais TRAIT IA ne doit avoir accès qu'à une liste de routes autorisées.

Créer un système de navigation contrôlé.

L'IA ne doit jamais pouvoir inventer une URL arbitraire.

## 17. RESPONSIVE

L'interface doit être parfaite sur :

* téléphone ;
* tablette ;
* ordinateur.

Sur mobile, privilégier une expérience plein écran.

Sur desktop, utiliser une largeur maximale confortable pour le chat.

Toutes les cartes, boutons et messages doivent rester parfaitement alignés.

## 18. ANIMATIONS

* apparition progressive des messages ;
